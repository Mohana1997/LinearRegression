# LinearRegression
This repository showcases my work on predicting MPG (miles per gallon) using a cars dataset. The project flow involves,
Data Collection and Exploratory Data Analysis (EDA): I started by gathering the dataset and performing EDA to understand the data’s structure and key features.
Assumption Checks: Before building models, I verified that the dataset met the assumptions for linear regression.
Model Building with and without Train-Test Split: I built models both using a train-test split and OLS, to compare how the model performs under different validation setups.
Evaluation Metrics: After building the models, I evaluated their performance using metrics like R² and adjusted R² to choose the best model.
Predictions and Insights: I used the final model to generate MPG predictions and provide insights into which features are most influential.
